# 여러 장 입력 Thresholding A/B/C 실험

고정된 ArcFace/DeepPrint의 기존 512차원 임베딩 캐시를 사용한다. 특징 추출기,
원본 이미지, 이전 실험 코드를 변경하지 않는다. 기본 조건은 모달리티별
**등록 5장, 질의 1장**이며 A/B 기준선 평가 후 C만 seed 17/29/43으로 학습한다.

| 실험 | 등록 표현 | 질의 표현 | tau |
|---|---|---|---|
| A | 등록 5장 중 사전에 무작위로 지정한 1장 | 동일 질의 1장 | 0 |
| B | 등록 5장의 평균을 L2 정규화 | 동일 질의 1장 | 0 |
| C | B와 같은 대표 벡터 | B와 같은 대표 벡터 | 모달리티별 512차원 예측 |

A의 등록 이미지는 B/C의 등록 집합에 포함된다. 질의는 모든 실험에서 동일하다.
A/B는 학습 파라미터가 없으므로 각 한 번 평가한다. C의 seed 수만큼 기준선을
복제해 독립적인 반복 실험처럼 집계하지 않는다. 기본값은 기준선 2개와 C 학습 3회다.

## 실행

```bash
cd /home/uxm2/hsh/2026_2/multimodal_biometric
bash feature_extractors/run.sh scripts/train_thresholding_multisample_abc.py \
  --device cuda --seeds 17 29 43 --epochs 100 --patience 20 \
  --enroll-captures 5 --query-captures 1
```

입력·샘플 구성만 확인하며 학습과 결과 폴더 생성을 하지 않는 명령:

```bash
bash /home/uxm2/hsh/2026_2/multimodal_biometric/feature_extractors/run.sh \
  scripts/train_thresholding_multisample_abc.py --check-only
```

별도 실험으로 등록 3장·질의 3장을 비교하려면:

```bash
bash /home/uxm2/hsh/2026_2/multimodal_biometric/feature_extractors/run.sh \
  scripts/train_thresholding_multisample_abc.py --device cuda \
  --enroll-captures 3 --query-captures 3 --seeds 17 29 43
```

이 경우 A는 등록 집합 1장·질의 집합 1장을 사용하고, B/C는 양쪽 3장씩을 집계한다.
UareU는 같은 손가락당 8장이므로 등록 장수+질의 장수는 8 이하여야 한다.
부족한 이미지를 복제하거나 등록·질의 사이에 공유하지 않는다. CUDA가 없으면
명확한 오류로 종료하며 자동으로 CPU 학습을 시작하지 않는다. CPU 실행은
`--device cpu`를 명시한다.

진행 중 epoch, 배치 진행률, 손실, 경과 시간, 단계 ETA와 전체 ETA 추정치가 표시된다.
ETA는 최대 epoch를 기준으로 하며 조기 종료 및 최종 평가 시간에 따라 달라진다.

## 모델

루트의 `Thresholding_Model_Set.py`에 `SetThresholdingModel`을 정의한다.
입력은 얼굴 `(B,Nf,512)`, 지문 `(B,Np,512)`이며 각각 동일인/동일 손가락의
반복 촬영으로 구성한다. 두 모달리티의 촬영 순서나 장별 대응을 가정하지 않는다.

각 모달리티별 통계:

1. L2 정규화된 장별 임베딩의 평균을 다시 L2 정규화한 대표 벡터: 512차원.
2. 장별 임베딩 좌표의 표본 표준편차: 512차원. 대표 벡터를 재정규화하기 전,
   원래 단위 임베딩들에서 계산한다.
3. `log(1+촬영 장수)`: 1차원.
4. 표준편차 관측 가능 여부: 1차원. 2장 이상이면 1, 한 장이면 0.

총 1026차원이다. 한 장 입력의 표준편차는 0으로 채우되 관측 불가능 표시가
함께 들어간다. 한 장의 표준편차 0을 높은 신뢰도의 근거로 해석하지 않는다.
이 모델은 신뢰도 확률을 학습하거나 출력하지 않는다.

얼굴/지문 branch는 각각 `1026→128→64`, 결합부는 `128→128→64`다.
모달리티별 head는 해당 branch 64차원과 결합부 64차원을 받아 `128→128→512`로
출력한다. hidden/context 크기는 옵션으로 조절할 수 있다. LayerNorm/GELU를
사용하며 BatchNorm, dropout은 사용하지 않는다.

```text
tau_m = 0.01*tanh(base_m) + 0.01*tanh(head_m(current_set_statistics))
bits_m = representative_m >= tau_m
```

기본 tau 범위는 [-0.02,0.02]다. 초기 tau는 정확히 0이며 C의 초기 비트열과
평가 지표가 B와 일치하는지 검사한다. 최종 비트열은 모달리티별 512비트다.
원본 임베딩을 추가 projection하거나 신경망의 중간 특징을 이진화하지 않는다.

등록 5장과 질의 1장은 **같은 모델에 별도로** 입력한다. 질의의 tau를 계산할 때
등록 통계나 등록 tau를 전달하지 않는다. 사용자 ID, 등록 비트열, FE 보조정보,
키는 모델 입력이 아니다. 학습에서 같은 비트열을 만들도록 유도하지만 tau 자체를
같게 만드는 손실은 사용하지 않는다.

공개 API는 원본 임베딩 집합을 받는 `forward`와 고정 캐시의 통계를 받는
`forward_statistics`다. 통계는 현재 입력 집합에서만 계산되므로 사람 간 통계
적합이나 질의를 이용한 등록 갱신이 없다. 저장/복원은 `save_checkpoint`와
`load_checkpoint`를 사용한다.

## 데이터 구성과 비교 범위

기존 원본 실험의 임베딩 해시, 사람별 분할, 가상 사용자 대응을 검증해 재사용한다.
얼굴 사람 수는 학습/검증/시험 220/28/28명, 지문 실제 사람 수는 5/1/1명이다.
동일인의 모든 손가락은 같은 분할에 있다. 얼굴과 지문의 연결은 가상 대응이다.

기존 한 장짜리 등록·질의 쌍을 그대로 사용하는 실험은 아니다. 새로운 집합
평가 조건을 구성하고 A/B/C 전체에 똑같이 적용한다. 이전 V3 수치와 직접 차이를
계산하지 말고 이번 실행의 A를 기준으로 비교한다. A는 정면 우선 선택을 하지
않으며 B/C 집합에서 무작위로 정한 첫 등록 사진을 사용한다.

각 가상 사용자에 대해 촬영본을 섞고 질의 역할을 순환시켜 매 round마다 모든
촬영본이 질의에 최소 한 번 포함되도록 한다. 해당 질의 집합을 제외한 촬영본에서
등록 집합을 중복 없이 추출한다. 등록 집합은 해당 episode 안에서 고정된다.
여러 episode는 서로 다른 등록을 모사하며, episode 사이에는 이미지가 재사용된다.
이는 한 번 등록한 고정 템플릿의 장기 추적 평가나 서로 독립적인 표본 반복이 아니다.

학습은 epoch마다 새 집합을 구성한다. 기본 `--train-rounds 1`이며 모든 학습 원본을
포함한다. 검증/시험은 고정된 `--evaluation-rounds 2` 집합을 모든 seed와 실험에
공유한다. 양쪽에 같은 원본이 들어가는 episode는 허용하지 않는다. 7,510개의
랜드마크 행이나 반전본을 독립 원본으로 사용하지 않는다.

기본 입력 검증에서 확인된 고유 episode 수는 학습 2,985, 검증 750, 시험 790이다.
모든 원본 얼굴 3,755장과 지문 520장이 각자의 분할 내 집합 구성에 포함된다.
학습 epoch/옵션에 따라 중복 제거 후 episode 수는 달라질 수 있다.

## 손실과 체크포인트

V3의 손실을 그대로 재사용해 입력 집계 변경과 손실 변경을 동시에 하지 않는다.
순전파는 hard bits, 역전파는 sigmoid 기반 STE 대리 기울기를 사용한다.

- 동일인: `[max(Dg - 28, 0)/32]^2` (반경 32, 여유 4비트).
- 타인: margin보다 가까운 쌍에 벌점. 기본 얼굴 224비트, 지문 160비트.
  서로 다른 신원 전체와 가까운 신원 상위 4개를 함께 고려한다.
- 신원 균형 가중치를 이용한 좌표별 0/1 균형.
- 개별 비트열의 1 비율이 [0.3,0.7]을 벗어날 때 벌점.
- 입력별 tau residual의 크기 억제.

가중치는 동일인/타인/좌표 균형/개별 편중 각각 1, residual 0.001이다.
학습은 등록 여러 장·질의 한 장이라는 비대칭 조건을 그대로 사용한다.

선택은 검증 분할의 **신원별 동일 가중 평균 <=32 비율**을 두 모달리티에 걸쳐
평균한 값을 우선하고, 동률에서는 평균 해밍거리 감소를 사용한다. C는 B 대비
모달리티별 반경 내 비율, FAR_h, 단일 모달리티 교체 FAR_h, AUROC와 비트 편중
조건을 통과해야 한다. 기준은 V3와 동일하며 `--max-*` 옵션으로 조절한다.
epoch 0이 선택되면 B와 동일한 tau=0 모델이 유지된 것이다. 학습이 실행되지
않았다는 뜻은 아니다. 마지막 학습 상태는 별도 `last_threshold.pt`에 남긴다.

모든 C seed의 선택이 끝난 뒤 시험 성능을 계산한다. 이미 과거 실험에서 시험
참여자 결과를 확인한 적이 있으므로 새로운 독립 확증 시험으로 표현하지 않는다.

## 결과

새 `thresholding/results/multisample_abc_<시각>/` 폴더를 생성한다. 기존 결과를
덮어쓰지 않으며 자동 재개는 지원하지 않는다.

- `comparison.csv`: A/B/C, seed, 모달리티, 분할별 지표와 A/B 대비 변화.
- `aggregate.csv`: C seed 평균·표준편차. A/B는 각 1회 측정.
- `paired_deltas.csv`: B-A(집계 효과), C-B(tau 추가 효과).
- `report.json`, `config.json`, `status.json`: 전체 보고서, 설정·해시, 완료 상태.
- `validation_sets.json`, `test_sets.json`: 사용한 원본 인덱스·파일명과 전체 집합.
- `train_epoch1_sets.json`: 첫 학습 집합. 이후 집합은 data_seed/epoch로 재현하며
  각 epoch의 집합·배치 해시가 C의 학습 이력에 기록된다.
- `A/`, `B/`, `C_seed*/`: 평가 보고서와 실제 bits/tau 배열, episode별 파일명.
- `C_seed*/best_threshold.pt`, `last_threshold.pt`, `history.jsonl`, `training.log`.

동일인 거리 평균/p95, <=32 비율, 0비트 오류율, FAR_h, 비트 균형, tau 변동,
두 모달리티 동시 반경 진입률을 기록한다. 지문은 같은 사람의 다른 손가락과
다른 사람을 구분한다. 검증/시험은 실제 지문 참여자가 각각 1명이므로 다른 사람
지문 FAR_h는 **null**이다. 이를 0으로 해석하지 않는다.

이 실험은 실제 BCH 복호나 암호 키 복구를 실행하지 않는다. <=32는 복호 전
해밍거리 기준이다. 새 집계/이진화 규칙을 실제 시스템에 쓰려면 등록 비트열과
FE 보조정보를 그 규칙으로 다시 생성해야 한다.
